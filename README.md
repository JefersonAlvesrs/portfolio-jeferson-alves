# Portfólio — Jeferson Alves

Portfólio pessoal com visual escuro e tecnológico, desenvolvido com HTML, CSS e JavaScript, reunindo sites comerciais, projetos frontend e uma aplicação full stack.

## 🌐 Projeto online

https://jefersonalvesrs.github.io/portfolio-jeferson-alves/ (publicar e ativar GitHub Pages).

## ✨ Funcionalidades

- Layout responsivo para desktop, tablet e celular
- Menu mobile funcional
- Filtros por categoria de projeto
- Cartões expansíveis com detalhes e tecnologias
- Links para os repositórios identificados no ZIP enviado e demonstrações confirmadas
- Botão para voltar ao topo
- Navegação acessível e respeito à preferência por movimento reduzido

## 🛠️ Tecnologias

HTML5, CSS3 e JavaScript (sem frameworks).

## 📁 Estrutura

```text
portfolio-jeferson-alves/
├── index.html
├── style.css
├── script.js
├── README.md
├── assets/
│   └── images/
└── imagens/
```

`assets/images` contém as 12 capturas reais enviadas dos projetos e `imagens` para capturas do README.

## ▶️ Como executar

Abra `index.html` no navegador ou use Live Server no VS Code.
